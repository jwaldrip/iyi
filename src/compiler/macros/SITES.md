# Macro sites: the prelude and the port's own source

Generated by `bench/macro_sites.py` from the dumps of `bench/selfhost_macros_exercise.sh`.
To regenerate: `MACRO_GATE_KEEP=<dir> bash bench/selfhost_macros_exercise.sh`, then
`python3 bench/macro_sites.py <dir>/sites --table src/compiler/macros/SITES.md`. Do not edit by hand.

Scope: every `.iyi` file in `src/iyi` and `src/compiler`. A site is one top-level `{% if %}`,
`{% for %}`, `{{ }}` or `verbatim` node: the unit the hosted compiler expands. Both sides use the
host target. A site is `identical` when the oracle and the port agree on its text, or on how it
fails. The oracle is the hosted compiler's expansion of the file parsed on its own, with no type
information, so a site that reads a type is `needs-context` or fails on the oracle side.

The `identical` count is the scoreboard and may only rise. The count of files the hosted parser
cannot read may only fall (`bench/macro_sites.floor`).
